# Phase 6 operator-read fixtures — AUTHORED, NOT GENERATED

These files are hand-written case tables for `tests/test_operator_read_fixtures.py`. They are
**not** produced by `tools/gen_list_read_contracts.py` and must never be moved under
`docs/phase6-list-read/fixtures/`, which that generator owns and CI regenerates.

They also live under `tests/data/` rather than `tests/fixtures/` on purpose.
`tools/freeze_contracts.py` inventories every file under `tests/fixtures/` into the Phase 0
frozen baseline, so a case table there would move a frozen hash — and a hashed shared file
regenerated by a lane that publishes no contract is a merge conflict with no meaning. Nothing
in this lane moves a frozen hash; a test asserts that this directory stays out of that root.

They exist because the generated fixtures show what a *receipt* looks like for each
classification, while the rules underneath a receipt — which pins are refused, which ranges
are never read, which cells are suppressed, which field paths may never be retained anywhere,
and which retention windows are still an operator's decision — had no worked, executable
examples. A rule with no example is a sentence, and a sentence does not fail a build.

Every case is offline: no socket, no store, no cluster, no clock, no credential. The tests
drive `hear/verify/list_read.py`, `hear/verify/shadow_read.py` and `hear/ingest/reconcile.py`
directly and compare against the expectations declared here, so a behaviour change either
updates a fixture deliberately or goes red.

| File | What it pins |
|---|---|
| `manifest.json` | the set, its source modules, and the case counts |
| `cursor-pins.json` | opaque-cursor consistency and pin refusal semantics |
| `export-bounds.json` | bounded export equivalence, and the refusal of the unbounded dump |
| `aggregate-k-anonymity.json` | closed dimensions, k-suppression, cell-value redaction |
| `never-retained-fields.json` | §4.2 of `docs/phase6-read-audit-retention.md`, as paths |
| `receipt-minimisation.json` | the exact field set a receipt may carry, and the names it may never carry |
| `retention-windows.json` | family → class → window classification, and what is still undecided |
| `read-authority.json` | legacy is the sole read authority; nothing live is enabled |

Nothing here authorises a read path, an API, an auth check or an audit table. If a future
change makes one of these cases wrong, the case is the thing to argue with first.
